GitHub basics: 
1. git config to set up my username + email 
2. git init to create a new repo locally in my proj folder 
3. git clone to copy a repo from GitHub and store it locally 
git clone git@github.com:richadhakal101/reponame.git
4. git status shows me which files are changed/untracked/staged which is useful to see before I commit a change 
5. git add filename.txt tracks a specific file, to track ALL changes use git add.
6. git commit -m "explain what code does as a whole"
7. git checkout -b SHOTPT-808 to create a new branch with the JIRA story number 
8. git log to see a history of commits 
9. git branch to see all branches 
10. git branch newbranchname to create a new branch 
11. git switch newbranchname to switch branches 
12. git pull origin main to update local directory with all of the latest changes 
13. git push origin branchname to send commits to the repo/make changes visible on GitHub. 
14. git branch newbranchname to create a new branch and use git switch xyzxyzxyz to switch branches
